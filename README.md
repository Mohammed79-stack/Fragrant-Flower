## 🚀 Getting Started

**1. Clone the repo**

```bash
git clone https://github.com/Mohammed79-stack/fragnentflower.git
cd fragnentflower
```

**2. Install dependencies**

```bash
npm install
```

**3. Run the development server**

```bash
npm run dev
```

**4. Open [http://localhost:3000](http://localhost:3000) in your browser.**

## 📁 Project Structure
